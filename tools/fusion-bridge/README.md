# Fusion 360 MCP bridge

Даёт Claude Code доступ к **запущенному** Fusion 360: прочитать текущее выделение
и выполнить произвольный скрипт по Fusion API.

## Из чего состоит

| Файл | Что делает |
| --- | --- |
| `ClaudeBridge/ClaudeBridge.py` | Add-in, живёт **внутри** процесса Fusion. Поднимает приватный HTTP на `127.0.0.1:9765`. |
| `ClaudeBridge/ClaudeBridge.manifest` | Манифест add-in'а (имя файла обязано совпадать с именем папки). |
| `fusion_mcp_shim.py` | stdio-MCP-сервер. Claude Code говорит с ним по MCP, он с add-in'ом — по HTTP. |
| `run-shim.cmd` | Запускает шим встроенным питоном Fusion. |
| `../../.mcp.json` | Регистрирует сервер под именем `fusion360`. |

Почему две части, а не один MCP-сервер по HTTP прямо в Fusion: хардкодить
MCP Streamable HTTP (согласование версии протокола, SSE, `Mcp-Session-Id`)
руками — куда больше шансов ошибиться, чем в stdio, где всё сводится к
«прочитал строку → отдал строку». Приватный протокол между шимом и add-in'ом
мы определяем сами, спецификации соблюдать не нужно.

Обе части — только stdlib: у встроенного питона Fusion нет pip.

## Ключевое ограничение: главный поток

Fusion API можно трогать **только** из главного потока Fusion. Поэтому HTTP-поток
никогда не зовёт API напрямую: он кладёт задание в словарь, бросает custom event
с одним лишь id задания и блокируется на `threading.Event`. Обработчик события
выполняется в главном потоке, делает работу и отпускает ожидающего.

## Запуск (ручной шаг, автоматизировать нельзя)

1. В Fusion 360: **Utilities → Add-Ins** (или `Shift+S`), вкладка **Add-Ins**.
2. Нажать **+** рядом с «My Add-Ins», выбрать папку
   `tools/fusion-bridge/ClaudeBridge` из этого репозитория.
3. Выбрать `ClaudeBridge` в списке → **Run**. Появится окно
   «Claude Bridge is listening on http://127.0.0.1:9765».
4. Галочка **Run on Startup** — чтобы не повторять это каждый запуск Fusion.

Проверка снаружи:

```bash
curl http://127.0.0.1:9765/ping
```

MCP-инструменты (`fusion_ping`, `fusion_get_selection`, `fusion_run_script`)
подхватятся после перезапуска Claude Code — регистрация в `.mcp.json` не
подключает сервер к уже идущей сессии.

## Единицы

Fusion API всегда работает в **сантиметрах**, независимо от единиц документа.
2 мм — это `0.2`. В скриптах есть готовые `mm()` (мм → внутренние см) и
`to_mm()`. Всё, что отдаёт `fusion_get_selection`, уже переведено в мм.

## Обновления Fusion

Встроенный питон лежит в `webdeploy\production\<хеш>\`, и хеш меняется при каждом
обновлении Fusion. `run-shim.cmd` ищет его на лету, поэтому обновление ничего не
ломает. Add-in, подключённый по пути из репозитория, обновления тоже переживает.
