# models/ — модели, скачанные со стороны

Здесь лежат **чужие** модели, относящиеся к корпусу и механике MBot Cube, вместе с атрибуцией. Это единственное место в `hardware/`, где допустимы файлы без нашего исходника: мы их не проектировали и переделывать «в исходнике» не будем — а если будем, переделка заводится отдельным каталогом по общим правилам из [`../../README.md`](../../README.md).

## ⚠️ Каталог пока пустой — файлы не скачаны

**Причина (проверено 2026-07-30):** список файлов вещи на Thingiverse отдаётся только через `api.thingiverse.com`, а он на запрос без ключа отвечает `401`. Сама страница `thingiverse.com/thing:NNNN/files` — это SPA: приходит JS-оболочка (~10 КБ) без единого имени файла. Обходные пути тоже закрыты: `/zip`-эндпоинт возвращает ту же оболочку, а веб-архив в этом окружении заблокирован сетевой политикой.

Метаданные при этом достать удалось (из og-тегов страницы), так что **что именно качать — известно точно**, см. таблицу ниже.

## Как заполнить

Вариант 1 — скриптом (предпочтительно, атрибуция проставится сама):

```bash
# токен: https://www.thingiverse.com/apps/create → тип "Desktop"
# положить в .env в корне репозитория:  THINGIVERSE_TOKEN=...
bash scripts/fetch-thingiverse.sh
```

Вариант 2 — руками: открыть каждую вещь в браузере, «Download All Files», распаковать в свой подкаталог по таблице ниже, и дописать атрибуцию в `SOURCES.md` (его создаёт скрипт; при ручном заполнении — завести самому по тому же формату).

## ⚠️ Лицензионное следствие, которое надо осознать до коммита

Две из трёх вещей — **CC BY-SA 4.0**. Это share-alike: указания автора мало, **производные работы обязаны идти под той же лицензией**. Практически это значит: если мы возьмём раскрой mbot3d и переделаем панель под свои нужды, наша переделка тоже CC BY-SA 4.0, и это распространяется на файл в `hardware/`, а не на весь репозиторий (у репозитория своей лицензии сейчас вообще нет — файла `LICENSE` в корне нет).

Третья вещь (Crixe) — CC BY 4.0, share-alike не требует, только атрибуцию.

Держать эти файлы у себя и переделывать их обе лицензии разрешают. Ограничение появляется в момент публикации производной — а репозиторий публичный, так что момент уже наступил.

## Про `thing:28499` — расхождение по рабочему объёму

Описание вещи (от самого производителя) говорит про **200 × 200 × 200 мм** и упоминает dual-экструдер. Это третья цифра в коллекции: официальный user manual даёт 220 × 220 × 180, обзорные сайты — 250 × 220 × 180 (см. `docs/bom.md`, раздел «Паспорт базовой машины»). Похоже, под маркой «Cube» ездило несколько ревизий с разным полем.

**Вывод для нас прежний и он важнее любой из этих цифр: реальные ходы осей у этой машины надо померить**, а не брать из паспорта — она перебрана, концевик X переставлен, стол заменён.
