# CAD — узел печатающей головы (`ultra-print-head-mount`)

Конструкторские файлы каретки. **Описание конструкции, размеры, требования и
ограничения — в `docs/print-head-mount.md`**, здесь только инвентарь и то, как
эти файлы получены.

## Что лежит

| файл | что это |
| --- | --- |
| `ultra-print-head-mount.f3d` | полный архив Fusion 360, вся история построения |
| `stl/big-part.stl` | половина с каналом GT2, в ориентации печати |
| `stl/small-part.stl` | вторая половина, в ориентации печати |
| `stl/stepper-mount.stl` | крепление мотора, в ориентации печати |
| `stl/cover.stl` | крышка, в ориентации печати |

Готовые проекты слайсера (OrcaSlicer, с поддержками и раскладкой) в репозиторий
не кладём — они в релизе:
<https://github.com/alex-mextner/ultra-3d-printer/releases/tag/print-3mf-2026-08-03>

## Состояние на момент выгрузки (2026-08-05)

Таймлайн **256 фич**, 39 тел в документе (из них печатных — четыре, остальные
справочные: `Nema17 model`, `NEMA17*`, вспомогательные `Body*`).

⚠️ **В `.f3d` детали разведены, а не в сборочном положении.** `big part` смещён
на **+40 мм по Y** относительно сборки — в модели он лежит на y 54.33…130.0,
в сборке 14.33…90.0. Остальные три стоят в сборочных координатах. Все размеры в
`docs/print-head-mount.md` даются **в сборочных координатах**, если явно не
сказано иначе.

## Как получены STL

Не через диалог экспорта, а скриптом по Fusion API — поэтому воспроизводимо:

1. `body.meshManager.createMeshCalculator()`, качество
   `VeryHighQualityTriangleMesh`;
2. к вершинам применяется матрица ориентации печати (см. таблицу ниже);
3. деталь центруется по X и Y и сажается на **Z = 0**;
4. пишется бинарный STL, нормаль треугольника считается из обхода вершин.

| деталь | матрица | габарит после ориентации, мм | прилегание к столу |
| --- | --- | --- | --- |
| `big-part` | поворот 180° вокруг X | 53.2 × 75.7 × 17.0 | 1853 мм² |
| `small-part` | без поворота (грань z = 0 вниз) | 53.2 × 41.0 × 17.0 | 2095 мм² |
| `stepper-mount` | поворот −90° вокруг X | 53.2 × 80.7 × 47.2 | 3387 мм² |
| `cover` | поворот 180° вокруг X | 53.2 × 47.2 × 9.8 | 329 мм² |

Ориентация `big-part` **не произвольна** — это требование, а не удобство:
зубцы GT2 должны смотреть вверх. Обоснование в `docs/print-head-mount.md`,
раздел «Ориентация при печати». Остальные три выбраны автоматически по критерию
«максимальная площадь плоской грани, оказавшейся на столе».

## Как перевыгрузить

Fusion должен быть открыт **с этим документом** (после перезапуска он поднимается
с пустым `Untitled` — документ нужно открыть явно, id лежит в
`docs/print-head-mount.md`). Дальше через MCP-сервер Fusion:

- `.f3d` — `design.exportManager.createFusionArchiveExportOptions(path)` +
  `execute`;
- STL — скриптом по шагам выше.

⚠️ Соединение с MCP-сервером Fusion в этой сборке рвётся само по себе, и после
разрыва Fusion поднимается с пустым документом. Если скрипт вернул
«Unable to connect» или тела не находятся по имени — сначала проверить, какой
документ активен, и переоткрыть нужный, а не искать ошибку в скрипте.
