# ultra-3d-printer

Апгрейд старого фанерного 3D-принтера **mbot cubic** до современной машины на **Klipper**: новый экструдер, современные шаговые драйверы, камера, автоматическая калибровка стола и полный веб-стек управления вместо родной прошивки.

## Основные характеристики

**Кинематика и рама**
- Картезианская кинематика (`cartesian`), унаследована от рамы mbot cubic.
- Три независимо откалиброванные оси X/Y/Z с механическими концевиками.

**Управление и прошивка**
- [Klipper](https://www.klipper3d.org/) вместо родной прошивки Marlin/аналогов — хост считает кинематику, MCU только исполняет шаги в реальном времени.
- Хост: **Orange Pi One** (Armbian) — Klipper, [Moonraker](https://moonraker.readthedocs.io/) (API) и [Mainsail](https://docs.mainsail.xyz/) (веб-интерфейс) через KIAUH.
- MCU: Arduino Mega2560 (Freaduino-клон) + шилд **RAMPS 1.4**.
- Веб-интерфейс Mainsail с полным контролем принтера, живым графиком температур и G-code консолью.

**Драйверы и точность**
- **TMC2209** на X/Y/Z — тихий режим `stealthChop` (перемычка SPREAD снята), 1/16 микрошага.
- Скорости: X/Y до 200мм/с, Z до 20мм/с — подобраны и подтверждены под нагрузкой.

**Экструдер**
- Современный **Dual Drive экструдер** (BMG-тип) вместо родного одинарного привода — двойной прижим филамента, передаточное число 50:17 через хоббированную шестерню 7.5мм.
- Драйвер A4988, скорость подачи до 50мм/с.
- Термистор 100K NTC 3950, нагреватель хотэнда 12В.

**Стол**
- Обогреваемый стол **K1 Max**, 1000Вт/220В переменного тока через твердотельное реле (SSR), нагрев до 120°C.
- Магнитная гибкая пластина для съёма деталей.
- Полная силовая обвязка 220В: отдельный предохранитель на AC-стороне, радиатор на SSR, механический термопредохранитель — независимая аппаратная защита от перегрева стола помимо программной (`verify_heater`).

**Автоматическая калибровка**
- Пробник **CR-Touch** для автоматического built-in bed mesh — не нужно вручную выставлять стол перед каждой печатью.

**Охлаждение**
- Три независимых вентилятора: обдув печатаемой детали (слайсерное управление `M106`/`M107`), обдув мотора экструдера (авто по активности моторов, через MOSFET-транзистор), постоянный обдув электроники.
- Увеличенный радиатор термобарьера экструдера.

**Камера и мониторинг**
- USB-камера, потоковое видео через [crowsnest](https://github.com/mainsail-crew/crowsnest), встроена прямо в интерфейс Mainsail — печать видно удалённо в реальном времени.

**Экран**
- Локальный экран + 5 физических кнопок на Orange Pi (SPI), [KlipperScreen](https://klipperscreen.readthedocs.io/) — управление принтером без веб-интерфейса, прямо у станка.

**Безопасность**
- Полная защита Klipper от теплового убегания (`verify_heater`) на хотэнде и столе.
- Независимая аппаратная защита стола по 220В (см. выше).
- `[force_move] enable_force_move` для безопасного джоггинга осей без доверенного хоуминга — удобно для машины, которая часто в апгрейде/ремонте.

## Структура репозитория

- [`docs/printer-status.md`](docs/printer-status.md) — статус проекта: что сделано и проверено, что в работе, история решений. Читать первым.
- [`docs/ramps-diagnostics.html`](docs/ramps-diagnostics.html) — методология: диагностика RAMPS/драйверов, подбор тока и скорости, безопасность 220В. Открыть через `docs/serve-ramps.sh` или напрямую файлом.
- [`printer-configs/`](printer-configs/) — живые конфиги Klipper/Moonraker/crowsnest, источник истины (правится только тут, см. `CLAUDE.md`).
- [`scripts/deploy.sh`](scripts/deploy.sh) — выкатка конфигов на принтер.
- Отдельно в `docs/` — заметки по попутному проекту миграции домашнего роутера на OpenWrt (не относится к принтеру).
